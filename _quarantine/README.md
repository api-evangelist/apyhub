# Quarantined artifacts — fabricated contracts

These OpenAPI definitions were **not** published by ApyHub. They were scaffolded
by an early enrichment pass from ApyHub's marketing copy: a single hand-authored
5-path `apyhub-openapi.yaml` that was then split by tag into four "APIs"
(Convert, Currency, Extract, Generate).

That scaffold is the sole reason apis.io listed **4 APIs** for a provider whose
real catalog is **451 services / 987 documented endpoints**.

Retained for provenance only. Do not reference, score, or republish.
Replaced 2026-08-18 by specs derived from ApyHub's own `llms.txt` service
documentation, with every path verified callable against `https://api.apyhub.com`.
