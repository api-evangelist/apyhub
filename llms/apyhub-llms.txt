# ApyHub

> Certified, production-ready APIs for the features every product eventually needs. One subscription, one bill, MCP-ready by default. Free tier, no card.

ApyHub is a marketplace of certified, production-ready HTTP APIs.
One API key and one subscription work across every service in the
catalog. Usage is metered in *atoms* (a per-call credit unit).
Every page on this site is also available as Markdown by appending
`.md` to its path or sending `Accept: text/markdown`.
