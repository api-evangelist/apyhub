ApyHub is a marketplace of certified, production-ready HTTP APIs. One API key and one subscription work across every service in the catalog, metered in 'atoms' (a per-call credit unit). The catalog spans 451 services from 19 providers across 21 categories - AI, file conversion and manipulation, data extraction and validation, SEO, geolocation, finance, HR and more - and is MCP-ready by default. Every page is available as Markdown by appending .md to its path.

**Areas:** API Marketplace · API Platform · Utility APIs · Document Conversion · Data Processing · Artificial Intelligence · MCP · Agent Ready

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ApyHub: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
